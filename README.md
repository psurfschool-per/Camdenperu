# CAMDEN PERU - Tienda Online

Ponchos 100% Producto Peruano.

## Desarrollado con

- HTML5
- CSS3 (Variables, Grid, Flexbox)
- JavaScript Vanilla (SPA)

## Funcionalidades

- Catalogo de productos con filtro por categoria
- Vista detalle de productos con galeria
- Carrito de compras funcional
- Proceso de checkout completo
- Notificacion por WhatsApp al confirmar pedido
- Totalmente responsive (desktop, tablet, movil)
- Animaciones suaves y transiciones

## Como ejecutar

```bash
python -m http.server 4000
```

Abrir http://localhost:4000
